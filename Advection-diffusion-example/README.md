# Neural Physics training examples

This folder contains an advection diffusion example written in a jupyter notebook (advection_diffusion.ipynb) with two python modules (Neural_Physics_utils.py Neural_Physics_boundary_conditions.py).

## Recommended environment

Python 3.10 or later is recommended. Install the packages listed in `requirements.txt`. For GPU execution, install the PyTorch build compatible
with the CUDA version on the training machine.

## Running the examples

```bash
jupyter notebook advection-diffusion.ipynb
